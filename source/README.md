# Source

- `wop-live.html` is the full page as it was served from Google Apps Script.
- `build_frameless.py` turns it into `../discover.js`: `python3 build_frameless.py wop-live.html ..`
- `template.html` is the editable template the page was built from.

- `ghl-embed.html` is the code in the GoHighLevel custom code box. `ghl-embed-old.html` is the previous framed version, kept so it can be put back in a minute.
